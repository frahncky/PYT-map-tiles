# PYT — Map Tiles

Este repositório existe só para hospedar, como [Releases](../../releases), o arquivo `.mbtiles` de mapa auto-hospedado usado pelo app [PYT](https://github.com/frahncky/PYT) — gerado a partir de dados abertos do [OpenStreetMap](https://www.openstreetmap.org/copyright) (© colaboradores do OpenStreetMap, licença ODbL).

Não há código-fonte aqui. O pipeline que gera o arquivo vive em `tools/maptiles/` no repositório principal (privado).

O app baixa a versão mais recente automaticamente, uma vez, na primeira abertura — não é preciso baixar nada manualmente daqui.
